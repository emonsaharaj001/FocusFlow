# FocusFlow — Study Tracker

FocusFlow is a responsive study tracking web application that helps students manage their study sessions, track focused time, and monitor their daily and weekly progress.

## Features

- **Study Timer:** Start, pause, resume, and finish study sessions.
- **Custom Subjects:** Add your own subjects to the subject list.
- **Daily Goal:** Track progress toward a daily study goal of 4 hours.
- **Dashboard:** View daily study statistics and subject summaries.
- **Weekly Progress:** Visualize your study activity throughout the week.
- **Study History:** Review recent sessions and delete unwanted records.
- **Local Storage:** Keep study records in your browser between visits.
- **Responsive Design:** Use the application on desktop, tablet, and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No backend or database setup is required.

## Data Storage

FocusFlow currently stores study sessions and custom subjects in the browser's Local Storage. Data is browser-specific and is not automatically synchronized across devices.

An unfinished timer session may not be recovered if the browser tab is closed or refreshed.
